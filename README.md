# [我不是牌神]七圣召唤自动牌手

BetterGI 七圣召唤 PVE 全自动牌手，提供雷神柯莱刻晴、伊安珊嘉明早柚、月绽放、莫娜早柚迪卢克、爱可菲林尼水形幻人、圣骸兽（特化对单）六套牌组。自动完成起手换牌、选人、重投骰子、出牌、元素调和、技能、切换和回合推进，角色阵亡后由存活角色继续接力。

- **雷柯刻**：雷电将军爆发补能，柯莱挂草激化，刻晴用雷楔返场、附魔普攻和爆发穿透衔接输出，支持新手版与完全版牌组。
- **伊嘉早**：伊安珊挂雷与增伤，嘉明负责火伤、超载和返场追击，早柚利用扩散与爆发兼顾多目标输出和治疗。
- **月绽放**：菈乌玛、哥伦比娅衔接草水反应与召唤物，奈芙尔使用诳言之核输出，结合减费、返骰、充能和生成牌选择安排行动。
- **莫早卢**：莫娜先挂水并快速交接，早柚留场扩散、准备攻击与爆发处理多目标，迪卢克利用蒸发、连续战技和爆发接力收尾；结合伙伴检索、装备减费、返骰与过牌增加行动机会。
- **爱林水**：爱可菲挂冰与生成料理，林尼通过隐具魔术箭积累余数、战技释放余数，水形幻人触发召唤物并接力输出；支持林尼四个技能槽、汤选择与「魔女M的祝福」召唤物选择。

- **圣骸兽**：飞蛇蓄能与爆发，毒蝎和角鳄接替承伤；结合后台天赋、能量块、倒计时与支援安排资源，主要面向普通PVE单体挑战，不承诺固定回合或特殊机制通关。

当前统一版本：**1.9.7**。共享层与六套牌手使用同一版本号，后续同步更新。

普通技能按当前出战角色和固定槽位释放，不再依赖技能名称或技能类别的文字识别；点击后根据实际骰子与战斗结果确认。

每套脚本均为独立包，保留牌面与界面识别模板，无需安装公共开发目录或其他牌手。使用说明、牌表、分享码及来源许可集中在各自的 README 中。

- 减少牌桌读取中的无效工作：确认敌方布局后才读取冻结状态，明确阵亡的己方角色不再读取充能；布局校验、识别门槛和动作等待不变。
- 雷柯刻统一选招规则，治疗、充能、调和、接力与装备准备在同一规划中比较；保留预算内已评估的最佳动作，没有值得执行的路线时明确结束回合。
- 雷柯刻保留本次技能采用的费用依据，确认后正确记账锐核／碎霆减费次数，避免返骰后继续按已耗尽的减费选招。
- 雷柯刻减少无收益的快切折返：能够直接使用刻晴战技时，不再为虚假的避险收益先切走、再用雷楔切回；真正的高血角色接力仍保留。
- 对局结束或脚本停止时，输出一条中文诊断摘要：结束情况、处理阶段、耗时、仍未读清的信息，以及最后动作是否提交和确认。
- 观察重试、输入未完成和确认失败的耗时也会计入，正常打完但输掉的对局与脚本异常停止分别说明。
- 摘要随原对局日志保存，不额外截图、不增加识别或等待；保留固定技能槽位、手牌识别和现有策略。

## 使用

使用 BetterGI 0.66.0 或更新版本、简体中文界面，支持1920×1080、2560×1440和2560×1600游戏客户区。开局前设置好分辨率，整局保持不变；切换后先重启 BetterGI 捕获器再启动牌手。

**画质要求：本脚本依赖画面识别，需要比较高的游戏画质。目前已知渲染精度至少需要设为 0.8，建议使用 1.0 或更高。** 低画质或过低的渲染精度可能导致手牌、费用图标、角色能量等识别失败。0.8 是目前已知的最低要求，不代表所有设备与画质组合下都能稳定识别。

在 BetterGI 的脚本仓库设置中选择自定义源，填写发布仓库地址：

```text
https://github.com/sxy8161-debug/bettergi-tcg-scripts-release
```

更新仓库后订阅所需牌手，按照对应 README 的角色顺序、牌表与启动步骤使用。每套均可独立运行，不需要安装其他牌手。

也可从 [Releases](https://github.com/sxy8161-debug/bettergi-tcg-scripts-release/releases) 下载单套脚本包，解压到 BetterGI 的 `User/JsScript/`；整仓库压缩包包含索引与各套牌手。

## 遇到问题时

请提供 BetterGI 日志中的`[对局摘要]`及对应脚本`logs/run-slot-01.log`至`run-slot-10.log`中的本次完整日志；可按日志首条`start`的时间找本局，不按槽位数字判断新旧。日志循环保留最近十次运行，求助前请及时取出对应文件。摘要中的缺读跨度不是纯等待时间，也不能直接确定画质或皮肤是原因；如果 BetterGI 被强行关闭或日志无法写入，可能没有退出摘要。
