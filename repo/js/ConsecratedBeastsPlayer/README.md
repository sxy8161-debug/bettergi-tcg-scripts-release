# [我不是牌神]圣骸兽（特化对单）

作者：巨鲸也是咸鱼。面向普通七圣召唤 PVE，以单体目标为主要用途。

所有挑战共用一套策略，无需切换挑战模式。按当前血量、手牌与骰子比较爆发和后续输出；同样能击倒当前目标时优先保留续攻资源，不为凑固定的后续伤害扣住已能使用的爆发。敌人复苏或进入新阶段后，直接按实际剩余血量继续规划，不预设复活血量或次数。

角色顺序固定为：**圣骸毒蝎 → 圣骸飞蛇 → 圣骸角鳄**，飞蛇首发。请使用下方完整牌表，不要更改角色位置或将角鳄换成骏麟；行动牌在编辑器中的排列顺序不作要求。

## 基础打法

起手保留璃月港口、风龙废墟、幻戏倒计时：3、立本、运筹帷幄和「沙中遗事」，包括这些牌的重复副本，其余置换。

飞蛇通过战技和星天之兆补能；没有星天时，比较可支付的战技或普攻。一次快速调和即可换来战技伤害和抽牌时，不只为少一次操作连打普攻；仍保留唯一未装备的天赋启动牌，蓄块时不随意调和唯一清洁工作。蓄能后通常切毒蝎承伤、发展支援，毒蝎受压时再考虑角鳄。组件与费用够用就比较爆发，不固定等到第几回合。没有必要时，两名辅助不额外消耗技能费用；续攻时优先当前可兑现的输出，不因队友稍多几点血来回切换。满能飞蛇尚未凑够伤害时，留在后台蓄块，不为了多打一发战技提前切回。飞蛇受压且能撤回时，保留块和能量交给健康队友承伤；没有撤回资金时再兑现现有爆发。已在场的健康飞蛇可战技补伤抽牌，当前补刀保持优先；爆发后的非补刀续攻由能承接行动的角色完成。普通过牌后，如果尚无成对能量块、没有补能用的星天，而天赋和增伤牌挤满手牌，就用沙中遗事换底寻找启动组件。

能量块每回合正常打出至多一张，只产骰、不充能。打出会舍弃其余手牌中当前费用最高的一张，并列时不能指定弃牌。亡雷可联动抽牌；倒计时被舍弃后将下一阶段置顶，沙中换底则不会触发降阶。所有来源的噬骸能量块共用同一零费规则，不因角标缺读逐张检视费用；原生明确费用修改仍优先。其他需要的未知费用才检视，不把付款优惠直接当成弃牌排序的费用变化。

飞蛇爆发以块数、绝缘、仙跳墙和清洁工作比较收益。同样能达到当前血量时，优先保留可支付的后续输出，利用换班时间节省切换费用，不为少一次零费准备白花骰子。后续输出也计入现有手牌调和、攻击补能再接爆发，不假设随机抽到新牌；每次只执行首步，再按实际结果重算。爆发后无法本回合完整收尾，也不会把所有致死攻击都过滤掉而空过或乱切。六块加绝缘、仙跳墙的裸伤是56，不等于能击倒60血目标；护盾、减伤、免死或阶段转换后，继续依据真实剩余血量行动，不把预计伤害当成胜利。满四个支援槽时不再新增支援，不自动替换已有支援。

倍率过量时，即使偶数块也可换取当前产骰、治疗和抽牌；仍按最差弃牌结果保留当前击倒伤害，不把随机抽牌计入现有资金。过量块也可在不丢掉当前击倒的前提下调色，少用万能骰付款；已有裸爆发足够时，不把仙跳墙当成必须保留的唯一组件。

续攻比较实际能打掉的血量与扩散波及，不为相同击倒的额外溢出伤害多调和。换班已经为撤退启用、且当前没有有效输出时，先完成切换，再按真实余骰铺付费支援。

辅助续攻将切换交棒与快速调和分开计价，不为少调和一次切出去、再改打更弱的技能。新出的仙跳墙和绝缘必须服务于该路线的飞蛇爆发，不仅为腾手牌而先出、随后改放战技。便携营养袋可能抽牌不妨碍利用已知增伤，未知抽牌不计入现有资源。续攻比较最多四次攻击，并计入现有星天之兆补能、清洁工作和合法能量块产骰；每步仍按实际资源重新决策。

## 使用条件

使用 BetterGI 0.66.0 或更新版本、简体中文界面。使用共享识别支持的1920×1080、2560×1440或2560×1600游戏客户区；需较高画质，已知渲染精度至少0.8，建议1.0或更高。开局前确定分辨率，整局不要切换。

核对下方分享码与固定角色顺序。在起手换牌、首次选人或首次掷骰阶段手动启动。行动阶段入口仅适用于新开局未行动，并须在设置中明确选择；不支持在任意进行中的对局接管。

单局超时保护默认15分钟，可选择10、20或30分钟。需要更长对局时，在启动前将「单局超时保护」设为30。识别未恢复时不重复提交同一动作；停止后先检查日志，不要在未知状态下反复重启。

不宣称覆盖特殊规则模式、100血以上目标或所有敌方机制，也不承诺固定回合通关。手牌外观不够明确时会补读标题；未知状态只限制依赖该信息的动作。
