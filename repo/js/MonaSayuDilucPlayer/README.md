# [我不是牌神]莫娜早柚迪卢克

莫娜、早柚、迪卢克的七圣召唤 PVE 自动牌手。莫娜挂水并利用快速切换交接，早柚通过扩散和风风轮舞踢应对多目标，迪卢克利用连续战技、蒸发和元素爆发收尾。根据实际敌方人数、血量、附着、骰子和手牌选择下一步，不预先排队执行整段连招。

自动处理起手留牌、选人、重投、调和、技能与切换；结合狼的末路、黄金剧团的奖赏、饰金之梦、赌徒的耳环、伙伴支援和琴音之诗安排装备与资源。每次行动确认后重新读取牌桌，阵亡时选择存活队友接力。

## 使用方法

1. 在七圣召唤中导入下方牌组，角色顺序保持 **莫娜／早柚／迪卢克**。
2. 使用简体中文游戏界面；游戏客户区固定为 1920×1080、2560×1440 或 2560×1600。切换分辨率后先重启 BetterGI 捕获器，不在对局中热切换。
3. 手动进入对局，在初始手牌、首次选人或首次掷骰页面运行脚本。默认不从中途行动页接管；“确认新开局未行动”仅用于刚开局且尚未进行任何行动的牌桌。
4. 脚本只处理当前一局；需要停止时使用 BetterGI 停止功能。

起手优先寻找迪娜泽黛、蒂玛乌斯、立本、幻戏倒计时和过牌。默认由莫娜首发；进入行动页后再根据实际敌方情况选择早柚或迪卢克接力。
