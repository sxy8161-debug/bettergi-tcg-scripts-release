# [我不是牌神]莫娜早柚迪卢克

莫娜、早柚、迪卢克的七圣召唤 PVE 自动牌手。莫娜先挂水并利用快速切换交接，早柚留场使用扩散、风风轮舞踢和元素爆发处理群怪，迪卢克利用蒸发、连续战技与元素爆发接力收尾。根据敌方人数、血量、元素附着、骰子和手牌选择当前行动，也会使用普通攻击补刀。

自动处理起手留牌、选人、重投、调和、技能与切换；结合狼的末路、黄金剧团的奖赏、饰金之梦、赌徒的耳环、伙伴支援和琴音之诗安排装备与资源，角色阵亡后由存活队友继续接力。

## 使用方法

1. 在七圣召唤中导入下方牌组，角色顺序保持 **莫娜／早柚／迪卢克**。
2. 使用简体中文游戏界面；游戏客户区固定为 1920×1080、2560×1440 或 2560×1600。切换分辨率后先重启 BetterGI 捕获器，不在对局中热切换。
3. 手动进入对局，在初始手牌、首次选人或首次掷骰页面运行脚本。默认不从中途行动页接管；“确认新开局未行动”仅用于刚开局且尚未进行任何行动的牌桌。
4. 脚本只处理当前一局；需要停止时使用 BetterGI 停止功能。

起手优先寻找迪娜泽黛、蒂玛乌斯、立本、幻戏倒计时和过牌。默认由莫娜首发；进入行动页后再根据实际敌方情况选择早柚或迪卢克接力。

## 战术说明

### 三名角色如何分工

- **莫娜负责启动反应**：先用水元素攻击给敌方挂水，元素战技还会留下虚影。莫娜的被动天赋让每回合第一次从她切出成为快速行动，但切换仍需支付骰子；配合换班时间可以省下切换费用。元素爆发提供泡影，能为后续角色攻击创造更高伤害。
- **早柚负责持续对群**：敌方有可扩散的元素附着时，用风伤把反应带到后台。战技包含首次攻击和之后的风风轮舞踢，元素爆发召唤不倒貉貉，兼顾后续攻击与治疗。装备狼末后，早柚的普通攻击也能用于低血补刀，不必每次都强求三颗风骰。
- **迪卢克负责接力与收割**：早柚阵亡、需要对单或进入残局时，由迪卢克继续输出。对带水目标使用火伤可以触发蒸发；流火焦灼配合连续战技节省骰子，第三次战技伤害更高，充能足够时再比较元素爆发与其他攻击。

### 开局与输出节奏

1. **先准备伙伴和过牌。** 起手寻找迪娜泽黛、蒂玛乌斯、立本、幻戏倒计时与运筹帷幄；黄金剧团的奖赏可为后续上场角色积累减费。迪娜泽黛配合其他伙伴能发挥减费与检索作用，蒂玛乌斯帮助取得和装备圣遗物。
2. **给后续输出准备水附着。** 默认莫娜首发。开局资源不能全部用于有效发育时，可以先用莫娜战技挂水；需要转入输出而莫娜尚未完成启动时，也会比较挂水后的扩散或蒸发收益。
3. **群怪阶段以早柚持续输出为主。** 莫娜挂水后，结合换班时间切到早柚。具备可扩散附着和足够骰子时使用风伤；骰色、充能或敌方剩余血量不同，也可能选择大招或普通攻击。敌方切人后，以新出战角色身上的附着判断反应，不能把后台的水当作前台已有水。
4. **残局由可用角色接力。** 早柚仍能有效处理群怪时保持输出；冻结、阵亡或对单收尾时重新选择行动。迪卢克利用已有水附着打蒸发，或用狼末强化的普攻补刀；需要更高单体伤害时，也会考虑莫娜泡影与迪卢克爆发的配合。

这些是牌组的配合方向，不是要求每局照抄同一套回合顺序。输出以当前实际可支付的攻击为准，抽到的牌和对手行动都会改变选择。

### 装备与伙伴怎样增加行动机会

- **狼的末路**：强化携带者伤害，面对生命值不高于 6 的目标时增伤更高。对群优先服务早柚的持续输出，迪卢克接力后也可装备自己的狼末。
- **黄金剧团的奖赏**：角色在后台积累减费，之后用战技或对应天赋牌兑现；不需要一拿到就立刻切换角色。
- **饰金之梦**：装备时提供对应角色元素的骰子，配合蒂玛乌斯、黄金屋、旧时庭园或琴音之诗降低费用，争取多一次可支付的攻击。
- **琴音之诗**：回收圣遗物并为下一次装备提供减费，可把已经完成作用的装备换成更适合当前局面的圣遗物。
- **野猪公主**：配合装备替换或角色阵亡时弃置装备回收骰子；装备较多的低血角色准备继续攻击时，也可以提前打出。
- **赌徒的耳环**：携带者出战时，击倒敌人可以补充万能骰，适合连续收割。需要同时考虑当前装备和换装成本。
- **立本与过牌**：立本利用回合结束时剩余的不同元素骰补充后续资源；运筹帷幄和幻戏倒计时补充手牌，重复或暂时用不上的牌可用于调和，但调和应服务于当前可完成的攻击。
